# Saved State (Phase 2: tensor-halfspace)

## Main refactor in this snapshot

- `HalfspacePolytope` stores tensor-native halfspaces:
  - `Halfspace(n::VectorValue, d::Real)`
  - no dense `(A,b)` storage as primary representation
- projection to local coordinates is tensor-based (`dot` with tangent basis vectors)
- optimizer penalty uses `halfspace_violations(hp, u)` directly

## Gridap extension style update

- methods are extended with explicit paths (no imports), e.g.
  - `Gridap.ReferenceFEs.num_dims(::HalfspacePolytope)`
  - `Gridap.ReferenceFEs.num_point_dims(::HalfspacePolytope)`
  - `Gridap.ReferenceFEs.GeneralPolytope(hp::HalfspacePolytope{D})`

## Notes

- 3D `GeneralPolytope(hp)` reconstruction now attempts face orientation correction
  before `polyhedron_from_faces`.
- Next planned step remains graph-oriented clipping backend inspired by STLCutters.
